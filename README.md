# Witkowski Studio

## loopy-loyalty-pricing/

Redesign concept for the Loopy Loyalty pricing page. Open `loopy-loyalty-pricing/index.html` in a browser; it is a single self-contained file.

- **Plan finder stamp card:** four questions (locations, staff, card designs, data export) answered by stamping. It recommends the smallest plan that fits and highlights it in the plans and the comparison table.
- **Plans as wallet passes:** each plan is drawn as an Apple/Google Wallet pass, with its limits shown as three numbers.
- **Monthly / yearly toggle** showing the per-month equivalent and the saving.
- Comparison table, FAQ and a closing call to action.

Prices and limits come from public listings (Starter $25, Growth $69, Ultimate $95 a month). Check them against the live site before use.
